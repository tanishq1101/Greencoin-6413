# GreenCoin — Design Direction

Inspiration: editorial sustainability site — deep forest green + cream, large nature photography, generous whitespace, calm and trustworthy. Mobile-first.

## Color
- Forest (primary): #14342B  / deep emerald #1B4D3E
- Moss / accent green: #2F6B4F
- Cream / paper bg: #F4F1E9
- Off-white card: #FBFAF5
- Charcoal text: #1E1E1B
- Gold (coins): #C9A24B  (coin gradient #E3C16F -> #B8862F)
- Muted/sage line: #D8D6C8

## Type
- Display: "Fraunces" (serif, editorial headlines) — weights 400/500/600, slight optical.
- Body/UI: "DM Sans" — 400/500/600.
- Numbers/coins: DM Sans tabular.

## Layout
- Mobile-first. Max content width ~480px shell feel on mobile, but responsive up to a roomy desktop dashboard.
- Bottom tab nav on mobile (Home, Log, Leaderboard, Redeem, More). Sidebar on desktop.
- Cards: soft rounded (16-20px), thin sage borders, subtle shadow. Lots of air.
- Balance pill visible on every main screen (gold coin + tabular number).

## Motion
- Page-load staggered reveal (Framer Motion). Coin count-up on balance. Celebratory pop on successful return/redeem (confetti-ish scale).

## Voice
- Warm, community, short, no guilt. "Nice work", "You're climbing", etc.

## Anti-patterns to avoid
- No purple gradients, no generic Inter, no cookie-cutter card grid. Use imagery + serif headlines for personality.
